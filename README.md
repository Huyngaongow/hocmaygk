Xem [hướng dẫn đầy đủ](52400013_52400102/README.md).

## Chạy chương trình

Từ thư mục gốc repo, chạy:

```bash
cd 52400013_52400102
python -m pip install -r requirements.txt
python de_5_ensemble_learning.py
python examples/toy_bagging.py
python experiments/report_extensions.py
python experiments/controlled_comparison.py
python experiments/ensemble_families.py
```

Dùng Python 3.11 trở lên; đã kiểm tra Python 3.12. Hướng dẫn môi trường ảo
cho Windows/Linux nằm trong README của thư mục mã nguồn.
Dữ liệu có sẵn trong scikit-learn. Kết quả được sinh trong thư mục `outputs/`
bên trong thư mục mã nguồn.
